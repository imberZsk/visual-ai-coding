# UI 与交互规范

## 设计基础

- 修改或新增 UI 前必须同时阅读本文件与 `style-standards.md`，二者是实现和验收约束。
- Ant Design 是基础组件系统；Tailwind 只承载已定义的语义变量和布局工具，不建立第二套颜色或组件体系。
- 优先使用 antd 组件、项目已有 UI 封装、语义 token 和 `@ant-design/icons`。熟悉图标不用手写 SVG。
- 产品是面向开发者的桌面工作台：保持安静、紧凑、便于扫描，不使用营销式大字、渐变、大阴影或装饰卡片。

## 间距与层级

- 布局间距使用 `4 / 8 / 12 / 16 / 24 / 32px`：4px 表示紧密关联，8px 表示同组元素，12px 表示关联内容，16px 表示子区块，24px 表示同级模块，32px 表示主要区域。
- 不为单个页面临时创造 6px、10px、14px、18px、20px 等布局间距。字号、行高、控件高度和固定列宽不属于布局间距，但需集中定义。
- 标签到控件为 8px，控件到说明文字为 8px，同组重复项为 12px，同级字段/模块为 16px 或 24px。
- 页面用全宽工作区和轻量分区建立层次。卡片只用于独立重复项、弹层或确需边界的工具，禁止装饰性卡片和卡片套卡片。
- 固定格式元素必须定义稳定尺寸或响应式网格，loading、长路径和动态文案不得使布局跳动。

## 字体、图标与侧栏

- 全局字体固定使用 `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，不得在页面或组件中另设展示字体。
- 正文和控件文字为 `14px`；侧栏导航、表格元信息和紧凑列表为 `13px`；辅助说明为 `12px`。页面标题统一 `20px`，区块标题为 `14px` 或 `16px`，不使用 `24px` 以上的运营式标题。
- 普通按钮、输入框和导航图标统一为 `14-16px`，导航图标固定 `16px`；只有产品标识可使用 `28-32px`，空状态插图或状态图标才可超过该范围。
- 桌面侧栏展开宽度固定 `200px`，折叠宽度固定 `56px`；窗口小于 `1024px` 时进入真实折叠模式，不通过裁切标签伪装折叠。导航行高为 `34px`，底部图标按钮为 `32px`。
- 侧栏右侧只允许由侧栏容器绘制一条 `1px` 分隔线，Ant Design Menu 自带边框必须清除；一级导航与模板子项均使用 `4px` 纵向间距，禁止菜单项零间距粘连。
- 普通 Ant Design 按钮沿用 Visual Worktree 基线：默认高度 `32px`、小按钮 `24px`、文字 `14px`，横向内边距使用同版本 Ant Design 默认 token。禁止用全局 `min-height` 把 small 按钮重新撑大；仅图标按钮和导航按钮可按其稳定尺寸单独收敛。
- `Marketplace` 与 `Plugins` 必须是工具分组下的独立入口：前者管理市场来源、本地索引与刷新，后者管理已安装插件的启停和版本；不要把市场列表伪装成插件列表，也不要用仅有视觉 Tab、没有独立数据语义的空页面。
- 字号、图标和侧栏尺寸必须由共享组件或相邻 CSS 集中维护，禁止在 JSX 中用任意值 utility 或行内样式单独放大。
- 内容侧栏的品牌区只显示产品名和副标题，不显示应用 Logo；应用图标只用于冷启动、Dock、安装包和系统级品牌入口，避免在狭窄导航中重复占位。折叠侧栏直接省略品牌区。
- 多 AI 工具导航一次只展示当前工具的一层能力入口；工具切换使用 Select 并持久化，不为每个工具重复创建可折叠二级菜单。
- 页面内相邻模块使用 `16px` 基础纵向间距，页面级大分组使用 `24px`；同类列表项使用 `12px`，不得依赖零散行内 margin 修补模块节奏。

## 颜色与组件

### Visual Worktree 标准色板

所有桌面项目使用 Ant Design 默认 seed `colorPrimary: #1677ff`，再分别通过 `defaultAlgorithm` / `darkAlgorithm` 派生主题；禁止按主题手写另一套 `colorPrimary`。当前锁定的关键结果如下：

| 语义                 | 亮色      | 暗色      | 使用场景                       |
| -------------------- | --------- | --------- | ------------------------------ |
| `colorPrimary`       | `#1677ff` | `#1668dc` | 主按钮、当前导航、焦点、链接   |
| `colorPrimaryHover`  | `#4096ff` | `#3c89e8` | 仅用于 hover，不能作为暗色主色 |
| `colorPrimaryActive` | `#0958d9` | `#1554ad` | 按下态                         |
| `colorPrimaryBg`     | `#e6f4ff` | `#15325b` | 低强度选中背景                 |
| `colorSuccess`       | `#52c41a` | `#49aa19` | 成功、完成                     |
| `colorWarning`       | `#faad14` | `#d89614` | 警告、需注意                   |
| `colorError`         | `#ff4d4f` | `#dc4446` | 错误、阻断、危险操作           |
| `colorBgLayout`      | `#f5f5f5` | `#000000` | 页面底层                       |
| `colorBgContainer`   | `#ffffff` | `#141414` | 侧栏和主要容器                 |
| `colorBgElevated`    | `#ffffff` | `#1f1f1f` | 卡片、弹层、浮层               |
| `colorBorder`        | `#d9d9d9` | `#424242` | 控件和主要边界                 |

- 业务组件必须消费 Ant Design token 或与上表一一映射的语义 CSS 变量，不直接写主色、状态色和主题中性色。
- 启动页无法读取 React token 时，允许静态使用上表的 `colorPrimary`；亮色为 `#1677ff`，暗色为 `#1668dc`。
- `#4096ff` 只能表示亮色 hover；不得再作为暗色默认主色、常驻图标色或 loading 色。
- 图表、代码高亮和第三方平台品牌色属于独立数据语义，必须使用专用变量，并且不能覆盖应用交互主色。

- 正文、次级文案、边界、背景和状态必须使用 Ant Design 主题 token 或 `--surface / --panel / --border / --accent / --text-* / --success / --warning / --danger` 项目语义变量。
- 主色只用于当前导航、主要操作、链接和焦点；红色只表示错误、阻断或危险操作；绿/黄只表示成功/警告。
- 布尔值用 Switch，模式用 Segmented，选项集用 Select，数字用 InputNumber，纯图标按钮必须有 `aria-label` 或 Tooltip。
- 同类列表操作位置保持一致；删除位于稳定行尾并使用 `danger`，不直接给图标写固定灰色或红色。

## 交互与状态

- Electron 主窗口不再额外展示原生标题栏；页面不得为拖动功能新增可见的空 Header。
- 侧栏品牌区与内容顶部 12px 热区承担窗口拖动，使用 `-webkit-app-region: drag`。
- 按钮、输入框、选择器、链接、菜单项和可编辑内容必须使用 `-webkit-app-region: no-drag`，不能为了扩大拖动范围牺牲交互。
- macOS 必须给交通灯保留安全间距；Windows/Linux 使用标题栏覆盖环境变量避让系统窗口按钮，不写死额外顶部空白。

- 页面专用流程留在页面或对应 hook，只有真实复用时才创建共享组件。
- 异步动作覆盖初始、loading、空、成功和失败状态；执行中防止重复提交。
- 失败提示包含失败对象和可操作原因，不能只显示“操作失败”。
- 高频操作保持直接可达，危险操作使用确认弹层；键盘焦点和可访问名称完整。
- Electron 冷启动在 React 首次提交前使用静态主题背景、居中的 `112px` 项目图标和图标下方的 Ant Design 默认四点 `Spin` 形态；loading 容器为 `20px`、单点为 `9px`、与图标间距为 `16px`。开发态 macOS Dock 和跨平台窗口图标必须使用仓库内 `1024px` 透明项目 PNG，打包态继续使用平台安装图标；不得显示 Electron 默认图标。

## 截图验收

1. E2E 必须使用无头/隐藏 Electron 窗口，截取关键页面的暗色和浅色状态。
2. 逐张检查页面层级、对齐、间距、文字截断、颜色语义、操作可达性和明暗对比度。
3. 窄窗口、长路径、长文案下不得出现重叠、裁切、横向溢出或不可达操作。
4. 检查 hover、focus、loading、空数据、错误和禁用态，不能只验收理想静态数据。
