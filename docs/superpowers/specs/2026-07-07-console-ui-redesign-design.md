# 控制台式 UI 大改设计规格

## 目标

将 Visual AI Coding 从顶部页签式界面改为更适合桌面配置工具的左侧控制台布局。功能保持不变，交互入口更稳定、更容易扫读，默认进入深色主题，同时保留浅色和跟随系统主题。

## 设计方向

采用“清爽桌面控制台”方向：左侧固定导航承载概览、Claude、Codex、Hooks、MCP、Agents、插件、技能；底部放主题切换和设置入口。右侧主内容保持原有页面和业务流程，只统一页面宽度、背景层次、卡片密度、Ant Design 控件外观。

## 视觉系统

深色默认主题使用墨蓝背景、低对比雾面面板、青绿色强调色。浅色主题使用白灰背景、清晰边界和同一青绿色强调色。颜色通过 CSS 变量提供给 Tailwind 和 Ant Design，避免组件内硬编码色值。

字体继续使用系统字体，保证 macOS Electron 应用的原生清晰度。字号维持 12/13/14/16/20 的紧凑工具型层级，不使用营销页式超大标题。

## 布局

应用根布局改为横向 flex。左侧栏宽度固定为 `w-60`，右侧主内容独立滚动。页面内容统一使用 `PageShell` 提供最大宽度和内边距，配置页和列表页获得一致的阅读宽度。

## 组件

继续优先使用 Ant Design。`Button`、`Drawer`、`Segmented`、`Table`、`Input`、`Switch`、`Alert` 等控件保留，使用全局 CSS 和 `ConfigProvider` token 调整为项目视觉。自定义导航项使用原生 `button`，因为左侧导航需要精细的选中态、图标、标签和焦点样式。

## 可访问性与反馈

主导航使用 `nav aria-label="主导航"`，当前项设置 `aria-current="page"`。图标按钮保留中文 `aria-label`。异步按钮继续展示 loading 并禁用。焦点态在深浅主题下都必须可见。

## 验收

- 默认偏好主题为 `dark`。
- 首屏仍通过入口 HTML 使用深色兜底。
- 应用显示左侧 sidebar，不再显示顶部 banner 导航。
- 主导航包含概览入口，设置入口不混入主导航。
- 深浅主题 token 与 Ant Design token 同步。
- 现有页面功能不变，测试和构建通过。
